# Security Policy

## Supported version

Security fixes are applied to the latest published Z²SE release.

## Reporting a vulnerability

Please do **not** open a public issue for a vulnerability that could expose user data, authentication material, local files, update integrity, browser-bridge security, or remote-code execution risk.

Instead, contact the repository owner privately through GitHub if possible and include:

- affected Z²SE version,
- clear reproduction steps,
- impact,
- proof of concept when safe,
- suggested mitigation if known.

Please do not include real credentials, cookies, tokens or personal data in the report.

## Scope

Security-sensitive areas include, among others:

- updater and release integrity,
- browser bridge request handling,
- local network exposure,
- command execution,
- file path handling,
- cookies and authentication material,
- third-party extraction providers.

Reports made in good faith are appreciated.

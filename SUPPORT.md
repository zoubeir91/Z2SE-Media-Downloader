# Z²SE Support

Thanks for using Z²SE Media Downloader.

## Before opening an issue

1. Update Z²SE to the latest release.
2. Run **Outils → Diagnostic système / Health Check**.
3. Retry the affected download once so Smart Recovery can run.
4. Check whether the problem affects FULL mode, PART mode, or Browser Bridge only.

## Bug reports

Use the repository's **Bug report** template and include:

- Z²SE version;
- Windows version;
- affected website/source;
- FULL / PART / Browser Bridge mode;
- exact reproduction steps;
- relevant log lines.

Do **not** post passwords, cookies, session tokens, authentication headers, private URLs, or other sensitive data.

## Feature requests

Use the **Feature request** template. Requests that keep Z²SE simple for everyday users while improving reliability, diagnostics, or usability are especially welcome.

## Security issues

Do not open a public issue for a security vulnerability. Follow `SECURITY.md` instead.
